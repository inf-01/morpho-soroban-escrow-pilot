# Morpho Soroban Escrow Pilot 🚀

Este proyecto es una solución de **Escrow Inteligente** para la red Stellar (Soroban) diseñada durante el Morpho Studio. Gestiona un contrato institucional de **$100,000 USD** dividido en 3 hitos clave.

## 🏗️ Estructura del Proyecto

- 📂 **`/src`**: Contiene el Smart Contract en Rust/Soroban con 5 roles institucionales y lógica de disputas.
- 📂 **`/dashboard`**: Interfaz de control visual (Mockup funcional) para supervisores y financieros.
- 📄 **`Cargo.toml`**: Configuración de dependencias de Soroban SDK.

## 👥 Roles Implementados
- **Institución:** Emisor de los fondos.
- **Proveedor:** Ejecutor del proyecto.
- **Supervisor Técnico:** Validador de hitos.
- **Encargado Financiero:** Ejecutor de pagos.
- **Árbitro:** Ente independiente para disputas.

## 🛠️ Tecnologías
- **Blockchain:** Stellar (Soroban SDK)
- **Lenguaje:** Rust
- **Frontend:** HTML5, CSS3 (Glassmorphism), JavaScript
